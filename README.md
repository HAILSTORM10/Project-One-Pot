# Project: OnePot
## All your Restaurant needs, All in one place 
<img width="1280" height="720" alt="Project OnePot V3" src="https://github.com/user-attachments/assets/185bb88c-93e2-444c-8a7c-49160e095842" />

Created as a Grade 11 I.T PAT, Project: OnePot aims to be the all-in-one solution to restaurant management like a hearty one-pot meal

### Login/Sign-up
To login, use the full name you entered during registration (Name + Space + Surname)
During sign-up, you will be asked for your Name, Surname, Password, Date of Birth and Phone Number. All of which will be stored in the database "OnePot.mdb"
This sign-up screen can only create Customer-type users. To create employees and Managers, use the Accounts page on the Admin Panel.

### Admins/Managers
The default log-in is Name: Admin Password: Admin
<img width="1594" height="869" alt="image" src="https://github.com/user-attachments/assets/8e8fb9b5-2577-4382-8230-4c1ffcd36857" />

Admins can view the restaurants inventory to manage stock and replace expired stock.
Replacing stock costs money, funds can be viewed from the stats panel.
Admins can view, add and delete users.
Admins can view interesting statistics about the restaurant.
Admins can view, edit and add to the menu.

### Employees
<img width="1589" height="888" alt="image" src="https://github.com/user-attachments/assets/c1642ddb-0c40-4773-9a80-b0ae2f2f0d67" />

Employees can take orders from the Menu panel. A total cost of an order is calculated and added to the business funds, which can be viewed in the stats panel.
Employees can view details regarding reservations made by Customers and Delete them.

### Customers
<img width="1590" height="879" alt="image" src="https://github.com/user-attachments/assets/917c3782-2feb-4b9d-a991-5837de7d1e13" />

Customers can make and view their own reservations from the booking panel.
Customers can view interesting information about their account from the loyalty panel.
